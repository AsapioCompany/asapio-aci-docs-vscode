Ticket Processing

ASAPIO is dedicated to delivering high-quality support processes. The process steps and corresponding ticket statuses are:

StepActionStatus
Customer creates ticketASAPIO starts processing the ticketOpen
Response to customerASAPIO waits for a responseWaiting on customer
ASAPIO has provided a solution–Resolved
Customer answers question–Open
Customer rejects the response–Open
Customer accepts solution (auto-close after 48 h)–Closed

Creating a Support Request

To access the ASAPIO Support Ticket system:

  • Visit asapio.com and click "Support" in the top menu.
  • Or open support.asapio.com directly.

Both options bring you to the login/overview screen of Freshdesk.

Login

If you have no user yet, proceed directly to create a new support request by clicking "New support ticket". New users can self-register at asapio.freshdesk.com/support/signup. Use your corporate e-mail address during registration.

Issue Description

To enable the ASAPIO support team to provide the best service, include the following in your ticket:

Administrative information

  • Who reports the error? (Contact name, phone, e-mail)
  • Which system and entity is involved?
  • How can the support user connect to the system?
  • How to escalate access issues (phone, e-mail)
  • Application and SAP release information
  • Potential business impact

Detailed issue description

  • Which application, process, and feature is affected?
  • How can the error be reproduced?
  • Preferred error solution tested in test instance – this must be done by the customer; ASAPIO cannot recreate the error.
  • What has been investigated so far?
  • Any modifications to the ASAPIO application or SAP standard
  • Information about relevant BAdI implementations (ASAPIO and SAP)

Checking Ticket Status

When logged in, go to the "Tickets" tab on the start page to review the status. You will receive e-mail notifications for all status changes and replies from a support agent.
