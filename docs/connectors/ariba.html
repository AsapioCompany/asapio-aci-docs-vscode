SAP Ariba® Connector

Overview

The ASAPIO Ariba Connector enables direct communication between SAP ERP / S/4HANA and SAP Ariba, allowing enterprises to orchestrate procurement processes across both platforms with real-time event-driven integration.

Key Features

  • SAP CIG supplement: Works alongside the SAP Cloud Integration Gateway (CIG) to extend and enhance Ariba integration scenarios.
  • Multi-system to multi-realm: Connect multiple SAP backend systems to a single or multiple SAP Ariba realms from a central configuration.
  • Non-harmonized master data: Handles environments where master data (materials, suppliers, cost centres) is not harmonized across systems.
  • MDG supplier integration: Supports SAP Master Data Governance (MDG) supplier scenarios where supplier master data changes in SAP trigger updates in Ariba.
  • SAP certified: The connector is certified by SAP, ensuring compatibility and adherence to integration standards.
